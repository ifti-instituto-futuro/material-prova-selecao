# Módulos de Estudo — Prova de Pré-Seleção

Bem-vindo ao material de preparação para a prova de pré-seleção. Esta pasta reúne três módulos de estudo que cobrem o escopo do **M1 (Fundamentos de Desenvolvimento)** da trilha de desenvolvedores — Git e fluxo Git SMN, lógica de programação e C# básico — e a parte de **SQL básico do M4 (Modelagem e Banco de Dados)**.

Cada módulo é independente e segue a mesma estrutura: um guia de estudos com teoria, estudo de caso e desafio, mais uma lista de exercícios práticos com cenário próprio.

## Módulos

| Módulo | Conteúdo | Cenário |
| :--- | :--- | :--- |
| [Git e Fluxo Git SMN](modulo-git-smn/README.md) | Git essencial, branches, merge e o fluxo corporativo da SMN. | Horizonte Sistemas (AgendaFácil) |
| [C# Básico](modulo-csharp-basico/README.md) | Lógica de programação, tipos, condicionais, loops, coleções e strings. | PedalUrbano (bicicletas compartilhadas) |
| [SQL Básico](modulo-sql-basico/README.md) | DDL, DML, SELECT, agregações, JOINs e subqueries no SQL Server. | CineVista (rede de cinemas) |

## Ordem Sugerida de Estudo

1. **Git e Fluxo Git SMN** — a ferramenta de trabalho que você usará desde o primeiro dia.
2. **C# Básico** — a base de lógica e programação.
3. **SQL Básico** — criação e consulta de dados relacionais.

Os módulos são independentes entre si; se preferir, estude-os em outra ordem ou em paralelo.

## Como Começar

1. Escolha um módulo na tabela acima e abra o `README.md` dele.
2. Siga a trilha de leitura do `guia_estudos` do módulo.
3. Resolva a lista de exercícios da pasta `exercicios` e o desafio do fim da aula.
