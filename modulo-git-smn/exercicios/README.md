# Guia de Exercícios: Módulo Git e Fluxo Git SMN (Horizonte Sistemas)

Bem-vindo aos exercícios práticos do módulo de Git.

Este guia consolida o conteúdo estudado na aula única do módulo, simulando o dia a dia de um desenvolvedor do squad AgendaFácil da Horizonte Sistemas. O foco é dominar o ciclo básico do Git, o trabalho com branches e o fluxo corporativo Git SMN.

---

## Estrutura dos Exercícios

A aula possui 3 exercícios organizados de forma incremental:

*   **[Aula 1: Git Essencial e o Fluxo Git SMN](aula1-exercicios.md)**
    *   Exercício 1: configuração, `init`, `status`, `add`, `commit`, `diff` e `log`.
    *   Exercício 2: branches de feature, alternância de branches e resolução de conflito.
    *   Exercício 3: o ciclo completo do fluxo Git SMN (Development, Staging e Main).

---

## Como Resolver os Exercícios

1.  **Ambiente:** basta o Git instalado (`git --version` para conferir) e um terminal. Cada exercício pode ser feito em uma pasta local vazia; não é necessário repositório remoto — onde houver `push`, o comando é ilustrativo.
2.  **Registro das respostas:** guarde os comandos executados (e as respostas discursivas) em um arquivo de anotações por exercício; isso facilita a revisão com o instrutor.
3.  **Validação:** use `git status`, `git log --oneline --graph --all` e `git branch` para conferir se o estado do repositório corresponde ao que o enunciado pede em cada etapa.

Atenção: tente resolver todos os exercícios por conta própria antes de pedir ajuda. Errar comandos e interpretar as mensagens do Git faz parte do aprendizado.
